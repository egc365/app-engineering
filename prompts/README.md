# Prompts

Mirror of the owner's master-prompt folder (`Documents/prompts/`).

- `STOP_AND_REPORT.md`: end-of-procedure protocol every agent runs when a
  project procedure ends or it is told to stop.

The master tuning prompt is maintained by the owner and is added here when
it is shared. Each problem seen in a run becomes a rule in the relevant
prompt and a category in the project's failure frequency chart.
